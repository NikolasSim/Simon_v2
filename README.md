# Simon — самообучающийся ассистент

Личный ИИ-агент в стиле Джарвиса: живой диалог, память, поиск знаний в сети,
уроки английского, перевод, напоминания с эскалацией, самоулучшение навыков
с обязательной проверкой, подтверждением и бэкапом.

## Сборка APK через GitHub Actions

1. Создайте репозиторий на GitHub и загрузите в него ВСЕ файлы этого проекта,
   включая скрытую папку .github/workflows/build.yml.
2. Вкладка Actions -> Build APK -> Run workflow.
3. Через 15-20 минут скачайте артефакт simon-apk (внутри APK).
4. Установите APK на телефон (разрешите установку из неизвестных источников).

## Возможности

- голос: Android TTS внутри APK, звуковые сигналы и сирена для напоминаний;
- wake-слово: "Симон, ...";
- память: memory.json — факты, имя, переводы, история;
- самообучение: вопросы без ответа копятся в очередь и разбираются при появлении сети;
- уроки английского: команда "учить английский";
- перевод: на английскую фразу предлагает перевод, после согласия переводит;
- самоулучшение: улучшения навыков проходят самотест, требуют вашего "да",
  старая версия сохраняется в backups, откат — командой "откатись";
- LLM: переменные JARVIS_API_KEY, JARVIS_API_URL, JARVIS_MODEL подключают
  любую OpenAI-совместимую модель для живой беседы.
